TURNSTILE - LIBERAR LOGIN NA PREVIA FLORIWEB

1. Acesse o painel Cloudflare.
2. Abra Turnstile.
3. Abra o widget que usa a mesma VITE_TURNSTILE_SITE_KEY do FloriWeb.
4. Settings -> Hostname Management -> Add Hostnames.
5. Adicione exatamente:
   floriweb-preview-rc611.joseluizacama.workers.dev
6. Salve.
7. Volte para a previa e use Ctrl+F5.

IMPORTANTE:
- Nao altere o Secret Key do Supabase.
- Nao altere o .env.
- Nao crie uma nova site key para este teste.
- A producao continua usando o mesmo widget; estamos apenas autorizando mais um hostname.
